Apresentação do projeto

Este site apresenta uma proposta de organização das informações sobre espaços esportivos universitários. O objetivo é demonstrar o uso de HTML5, links, listas, tabelas, imagens, mídias e formulários.

Importante: o formulário é apenas demonstrativo. Ele não envia, não salva e não confirma reservas.

Termos usados no projeto

UNEMAT é a sigla usada neste trabalho para identificar a instituição mencionada no tema acadêmico.

O arquivo principal do site chama-se index.html. A extensão .html identifica documentos escritos em HTML.

“A organização da informação facilita a navegação e a compreensão do conteúdo.”

O conteúdo acima é uma frase ilustrativa para fins didáticos.
