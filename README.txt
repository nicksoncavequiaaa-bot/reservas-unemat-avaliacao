AVALIAÇÃO 01 — INTRODUÇÃO AO DESENVOLVIMENTO WEB
Tema: Protótipo demonstrativo de reservas esportivas — UNEMAT Campus de Sinop

ARQUIVOS
- index.html: página inicial
- espacos.html: espaços esportivos, tabela e listas
- reserva.html: formulário demonstrativo com validação nativa
- funcionamento.html: fluxo, tabela, listas e vídeo demonstrativo
- imagens/espaco-esportivo.svg: imagem ilustrativa local

IMPORTANTE
- Este projeto não usa CSS, conforme os critérios da Avaliação 01.
- O formulário não cria nem salva reservas. Ele utiliza action="#" e validação nativa do navegador.
- O vídeo de exemplo depende de internet e não retrata instalações da UNEMAT.
- Revise o conteúdo com seu grupo e valide cada página em https://validator.w3.org/ antes da entrega.

PUBLICAÇÃO NO GITHUB
Envie os quatro arquivos HTML e a pasta imagens para a raiz do repositório. O README.md é opcional.
